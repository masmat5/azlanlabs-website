# AzlanLabs website

Static site — no build step. Open `index.html` or run `python3 -m http.server` in this folder.

- Brand tokens (colours, fonts, spacing): top of `styles.css` (`:root`).
- Contact email: `CONTACT_EMAIL` at the top of `main.js` (currently a placeholder).
- Fonts: Bricolage Grotesque (headings), Instrument Sans (body), JetBrains Mono (labels). Icons: Lucide.
